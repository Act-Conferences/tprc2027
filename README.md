# tprc2027
The Perl & Raku Conference 2027

This repo contains the front-end code for TPRC 2027, an annual multi-day North American Perl & Raku conference.

https://act.yapc.eu/tprc2027/

The master branch is automatically deployed to http://test.mongueurs.net/tprc2027/ for test purposes.
The production branch is automatically deployed to the act.yapc.eu url listed above.
